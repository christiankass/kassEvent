# Polices des billets

Polices utilisées pour écrire les champs propres à chaque billet (nom de l'invité, type, code)
sur l'image du billet créée dans l'éditeur. Les mêmes familles sont proposées dans l'éditeur.

Toutes sont sous licence SIL Open Font License 1.1 (Google Fonts) : Fraunces, Playfair Display,
Instrument Sans, Great Vibes, JetBrains Mono.
