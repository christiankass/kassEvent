Talon de contrôle
  • Nominatif. Le nom du titulaire figure sur le billet et dans le QR code : un billet copié se voit au scan.
  • Code unique lisible. Si le QR est abîmé, l'agent tape le code à la main.
  • Microtexte. La bande de petits caractères reprend le nom et le code : une retouche grossière se remarque.
  • Hors ligne. Une simple capture d'écran fonctionne à l'entrée, même sans réseau.
  • Organisateur en avant. Son logo et son nom ouvrent le billet ; kassEvent reste discret.
  • Jaune signature. Reconnaissable d'un coup d'œil dans une conversation WhatsApp.
